# 🛡️ CodeShield for VS Code & Cursor

This extension brings the **CodeShield Edge-Native Security Firewall** directly into your VS Code / Cursor IDE editor.

### Features
* **Status Bar Widget:** Live telemetry indicator showing Snapdragon NPU connection and latency.
* **Auto-Healing Integration:** One-click command healing for risky agent operations.
* **Quick Launch Console:** One-click launch to the Cyberpunk Web Security Console (`http://127.0.0.1:8000/console`).

### Installation
1. Open Cursor / VS Code.
2. In terminal: `python cli.py mcp` or configure CodeShield as an MCP tool provider.
3. Reload IDE window.
